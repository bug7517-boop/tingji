# 聽記：本機會議逐字稿

Windows 本機工具，透過瀏覽器操作。錄音、逐字稿與摘要皆保留在這台電腦；不需要 API 金鑰。

## 開始使用

### 在新電腦安裝（Windows 10／11，64 位元 x64）

1. 安裝 **Python 3.12（含 Python Launcher 與 pip）**及 **Node.js 22 LTS 或更新的 LTS 版本（含 npm）**。安裝後重新開啟命令視窗。可從 [Python 官網](https://www.python.org/downloads/) 與 [Node.js 官網](https://nodejs.org/) 下載。
2. 在 GitHub 按 **Code → Download ZIP**，解壓縮到自己的資料夾（例如 `C:\Tingji`）；也可以使用 Git clone。請先完整解壓縮，再執行裡面的檔案。
3. 雙擊 **setup.cmd**，等待 Python 套件安裝與網頁建置完成。
4. 雙擊 **下載模型.cmd**，等待辨識模型、摘要模型及摘要引擎下載完成。首次安裝需要網路；模型約 1.6 GB，建議預留至少 5 GB 可用空間，錄音資料另外計算。
5. 雙擊 **啟動聽記.cmd**，瀏覽器會開啟 <http://127.0.0.1:8765>。使用及處理錄音期間，請保留啟動視窗；重新開機後需再次啟動。

建議至少 8 GB RAM；較長錄音或較大模型建議 16 GB。預設使用 CPU，不需要 NVIDIA 顯示卡。此版本的自動下載摘要引擎適用 Windows x64，尚未提供 macOS／Linux 安裝流程。

GitHub 專案只包含程式碼，不含任何人的錄音、逐字稿、會議紀錄、金鑰、已下載模型或虛擬環境。朋友下載後需在自己的電腦完成上述安裝；每台電腦的資料各自保存。

### 日常使用

完成安裝後，雙擊 **啟動聽記.cmd** 即可使用。

1. 選擇或拖曳錄音。
2. 中英夾雜的會議選「中英混合（繁體）」；全中文會議選「全中文（繁體）」；全英文會議可選「英文」。全中文模式固定以中文辨識，仍以繁體中文輸出。
3. 按「開始轉錄」。完成一段就會保存；逐字稿和摘要在不同頁籤。
4. 點時間戳可回聽，搜尋可找到關鍵字。逐字稿可切換「顯示時間戳記／不顯示時間戳記」，TXT 匯出會跟隨選擇；SRT 字幕仍保留必要的時間資訊。摘要可匯出為 Markdown。

支援 MP3、M4A、WAV、FLAC、OGG、AAC、MP4、WebM、WMA、Opus。單檔最長 **3 小時**、最大 **4 GB**，依實際解碼樣本數再檢查一次時長。錄音「匯入」是從瀏覽器傳給同台電腦的服務，不會上傳到外部服務。

中文會轉為繁體中文，英文保留英文。逐字稿是模型辨識結果，可能誤聽、漏字；不是經人工校訂的正式會議紀錄。時間戳是段落級估計。此版本尚無自動發言者分離。

顯示設定也適用於雜音模式的雙版本試轉比較，並記住在這個瀏覽器的選擇。隱藏時間戳不會刪除原本的時間資訊，隨時可切回顯示，無須重新轉錄。

## 雜音錄音模式：先試轉，再處理整份

1. 在匯入區選擇 **雜音錄音模式**，選擇錄音、語言及已下載的辨識模型。
2. 設定 **試轉起點（分鐘）**、**3／4／5 分鐘**長度及**輕度／標準降噪**，按「先試轉比較」。例如起點 10 分鐘、長度 3 分鐘，就是比較原始錄音 00:10:00～00:13:00。
3. 工具會停在比較畫面，顯示同一範圍的原音／降噪版逐字稿及播放器。兩版都保留絕對時間戳，點擊時間戳會跳到試聽片段中的相應位置。
4. 可以更換起點、長度或強度，按「重新試轉」；不必重新匯入同一檔案。剩餘錄音不足指定長度時，會比較至檔案結尾。
5. 按「用原音處理整份」或「用這個降噪設定處理整份」，才會開始整份錄音的轉錄，以及你選擇的自動摘要。未試轉的降噪設定不會直接套用到整份。

降噪使用 PyAV 內建 FFmpeg 的高通與 `afftdn` 濾鏡，不需要另外下載執行檔或把錄音送到雲端。原音副本會保留，降噪產生另一份 WAV。處理不刪除停頓、不改變播放速度，補償濾鏡的訊號延遲，並維持相同樣本數。中文仍轉成繁體中文，英文仍保留原文。

試轉與整份處理都可以暫停、續跑；試轉已完成的一個版本會保存，續跑時不必重做。開始整份處理後，設定即固定；原本的試轉結果仍可展開查看。若要改用其他設定重新處理已完成的整份錄音，請建立一份新紀錄。

降噪不一定能提高辨識準確度。請比較是否漏字、錯字、削掉人聲，不要只比較音量。各時間點的雜音不同，試轉效果也不代表整場會議的每一段。此模式不會自動宣稱哪個版本較準；多人重疊發言、嚴重爆音及回音仍可能難以辨識。

雜音模式額外儲存兩個試聽片段，以及整份降噪 WAV（選原音則不產生整份降噪檔）。最長三小時的降噪 WAV 約 346 MB；兩個五分鐘試聽片段合計約 19 MB。刪除會議紀錄時會一起清除。

## 長錄音、暫停與續跑

- 音訊以串流方式解碼為磁碟上的單聲道 16 kHz WAV，避免一次載入三小時的音訊到記憶體。
- 每 5 分鐘辨識一次，前後邊界有重疊音訊；依段落中點去除重複，時間戳回填原始錄音位置。
- 每完成一段，以原子寫入更新 JSON。暫停、服務中斷或重開工具後，可在「會議紀錄」續跑；尚未完成的一段會重做。
- 同時只處理一份錄音，其餘排隊，以限制 CPU 與記憶體使用。
- 摘要會讀取完整逐字稿，分批挑選「重點／決議／待辦／待確認」，並附上原文與時間戳。模型只回傳來源編號，輸出文字由逐字稿取回，避免摘要自行編造日期、人名或金額。分類仍可能有誤或漏選。
- 跨段的一般重點會再次篩選，已選出的決議、待辦與待確認事項則完整保留。摘要失敗保留逐字稿，可單獨重試摘要。
- 暫停需等當前模型操作完成，並非立即停止 CPU 工作。CPU 處理 3 小時錄音可能花數小時，速度取決於電腦、模型及錄音內容。

## 模型與離線使用

預設為 faster-whisper **small**（CPU int8）與 **Qwen2.5-1.5B-Instruct Q4_K_M**（llama.cpp CPU）。摘要模型優先節省記憶體；重要決議、人名、金額、負責人及期限仍應對照原始錄音。

首次安裝執行 `setup.cmd`，再執行 `下載模型.cmd`。預設模型合計約 1.6 GB，另需套件及磁碟空間。若下載中斷，重新執行；模型下載工具可利用已下載的快取。準備完成後，轉錄與摘要不會自動連線下載任何模型。

其他辨識模型可手動下載：

```powershell
.venv\Scripts\python.exe scripts\download_models.py --whisper medium --skip-summary
```

可選 `tiny`、`base`、`small`、`medium`。通常較大模型需要更多時間及記憶體。可先用短片段評估你自己的會議品質。

官方來源：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)、[Qwen 模型](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF)、[llama.cpp](https://github.com/ggml-org/llama.cpp)。摘要引擎固定使用 b6000，來源及 SHA-256 保存在 `vendor/llama-b6000/source.json`。使用與散布時請遵循各模型及套件授權。

## 資料位置

`data/jobs/<紀錄ID>/` 包含原始錄音副本、暫存 WAV 與 job.json。三小時的暫存 WAV 約 346 MB，原始檔會另外保留。從工具刪除紀錄會刪除這些副本及結果，不會刪除你最初選擇的錄音檔。資料不會自動清除，請視需求備份或刪除。

服務只綁定 `127.0.0.1:8765`，不供其他電腦連線。請勿將它公開到網路；這是供單一使用者使用的本機工具。

## 無法開啟時

- 出現 `ERR_CONNECTION_REFUSED`：先執行 **啟動聽記.cmd**，等待顯示服務已啟動，再重新開啟網址。關閉啟動視窗或關機後，網址就無法使用。
- 提示缺少 Python 或 Node.js：確認已安裝上述先決軟體，再重新執行 **setup.cmd**。
- 模型顯示尚未下載：執行 **下載模型.cmd**；若下載中斷可重新執行。選單列出其他模型不表示已安裝。
- 分享工具給朋友：分享 GitHub 專案連結即可。分享自己的完整資料夾會連同 `data/` 內的私人會議資料一起帶走，請留意。

## 開發與測試

後端：Python 3.12、FastAPI、PyAV、faster-whisper、OpenCC、llama.cpp。前端：React、Vite、Lucide。前端套件版本鎖定於 web/package-lock.json。

```powershell
# 前端正式建置
cd web
npm ci
npm run build
cd ..

# 啟動服務
.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8765

# 測試（需另裝 requirements-dev.txt）
.venv\Scripts\python.exe -m pytest tests -q --basetemp .test-run
```

測試包含：格式與來源限制、持久化與續跑、TXT／SRT 匯出、實際音訊重取樣、時長限制、三小時末段讀取、繁體轉換保留英文、長逐字稿摘要涵蓋及摘要失敗保留逐字稿。雜音模式另外驗證濾鏡延遲補償、樣本數與原檔保留、取消時清除未完成音訊、試轉絕對時間戳、試轉續跑、重試與整份處理設定限制。

若 Node 套件安裝遇到企業憑證問題，可在該 PowerShell 視窗設定 `$env:NODE_OPTIONS='--use-system-ca'` 後再安裝，無需關閉 TLS 驗證。

其他子資料夾若屬於不同工具，與本工具的啟動及資料流程無關。
